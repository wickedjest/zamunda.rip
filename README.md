# Zamunda.rip Stremio Addon

Този Stremio addon скрейпва началната страница на https://zamunda.rip и показва всички торенти в един каталог.

## Функции
- Единен каталог "Zamunda All Torrents"
- Автоматично извличане на заглавия
- Magnet линкове за Stremio
- Работи без акаунт
